Renders a Lucide glyph that inherits the surrounding text colour — use it for every icon instead of hand-writing SVG.

```jsx
<Icon name="timer" size="lg" />
<Icon name="users" size="sm" color="var(--text-muted)" />
```

Sizes: sm 14 / md 18 / lg 22 / xl 28, or a raw number. Icons are decorative by default (`aria-hidden`); put the label in the surrounding element.
