The standard action button — one `primary` per view, `secondary` for neighbours, `inverse` only on the dark presentation stage.

```jsx
<Button variant="primary" size="lg" icon="play">Lancer la session</Button>
<Button variant="secondary" icon="plus">Ajouter une question</Button>
<Button variant="ghost" size="sm">Annuler</Button>
```

Variants: primary / secondary / ghost / danger / inverse. Sizes sm 32 / md 40 / lg 52. Hover lightens, press insets and nudges 1px down.
