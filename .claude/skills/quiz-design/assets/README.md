# assets/

**Empty on purpose.** No logo, icon set, illustration, photography or font binary was provided with the brief, so nothing has been copied in and nothing has been drawn from memory.

- **Brand mark**: wherever a logo belongs, the product name is set in plain type — Space Grotesk 700, `letter-spacing: -0.03em`, in `--brand-700` on light grounds and `--stage-ink` on the stage. See `thumbnail.html` and the presenter side rail.
- **Icons**: [Lucide](https://lucide.dev) loaded from CDN (`lucide-static@0.441.0`) through the `Icon` component. Substitution — flag for review.
- **Fonts**: Google Fonts (Space Grotesk, Instrument Sans, JetBrains Mono) loaded over CDN in `tokens/fonts.css`; no self-hosted binaries.
- **Imagery**: none. Question media slots are left blank in the kits rather than filled with stock.

Drop real files here (`logo.svg`, icon sprite, illustrations) and update `tokens/fonts.css` plus this note.
